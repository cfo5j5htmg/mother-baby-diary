# 认识先兆早产

> 更新时间：2026-09-17 (UTC+8)

先兆早产是指妊娠28周至不满37足周之间分娩者。此时娩出的新生儿称早产儿，出生体重多小于2500G.临床上先兆早产多以预防为主，今天我们就来了解一下先兆早产的预防措施及发生后的治疗原则。

  预防措施

  1.  孕期避免过度劳累。 勿持重涉远、登高攀岩， 不宜穿高跟鞋，忌烟酒， 避免跌扑闪挫。
  2.   如有阴道出血应绝对卧床静心休养。并且及时到医院就诊。同时严禁房事。
  3、保持外阴清洁。有阴道炎应该及时治疗。
  4、 慎起居，避风寒，预防感冒。 
  5、 勿食有损于胎儿发育的药物。勿接触放射线。避免接触有毒物品。
  6、 大便应保持通畅，大便时不 要过于用力，以防止腹压升高而引起阴道出血。
  7、 居处宜清静，环境优幽， 避免近嘈杂、污秽之处。
  8、 饮食宜清淡，易于消化，但富有营养的食物，忌食辛辣动火之品，宜多吃蔬菜和水果。
  9、 不要精神过度紧张，多 卧床休息， 怡心养性， 并可进行胎教。

  如发生先兆早产相关症状，应立即来院检查。一经确诊，治疗原则如下

  1.控制宫缩，尽量维持妊娠至足月

  2. 据病情需要采取左侧卧位或头低足高位，病情较重者绝对卧 床休息。

  3. 禁止不必要的妇科检查，以减少刺激。

  4. 心理护理：宣传精神因素对恢复健康的重要性，引导孕妇以乐观的心态 对待病情。提供精神支持，解除家属和孕妇思想顾虑，增强保胎信心。 

  5. 观察病情：随时评估病人阴道流血及腹痛情况，若流血量超出月经量或 阴道有组织物排出，及时通知医师并保留组织物送病理检查。使用硫酸镁抑制宫缩者，按医嘱监测呼吸、脉搏、尿量及膝反射

  6. 健康指导：多进食膳食纤维丰富的蔬菜水果，以防便秘导致宫缩。
