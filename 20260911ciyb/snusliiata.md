# 【微新闻】广东省中医院这位工号0001的老专家94岁了！除了是一名医生，她还是……

> 更新时间：2026-09-11 (UTC+8)

4月26日，广东省中医院呼吸科病房装扮一新，花香飘逸，欢声笑语。这一天是医院内科学前辈肖玉英教授的94岁寿辰。当天，呼吸科全体医护人员向老寿星表达了最诚挚的祝福。

工号0001  呼吸内科奠基人

肖玉英教授1923年出生于福建建瓯，十七岁加入中国共产党，先后就读福建协和大学及国立中正医学院。**1972年到省中医院工作，她的工号是0001，是省中医院内科分科及建设的奠基人，也是呼吸科的第一代主任、当时省内一流的呼吸内科专家。**

她的到来，为省中医院内科建设带来了新气象，不仅成立了单独的呼吸内科病房，促进了大内科分科发展，更是带领呼吸科开展肺功能检测，成为当时国内最早开展肺功能检查的中医院之一，同时也将呼吸内科带入了快速发展的轨道。

【两位抗战老兵肖玉英和原医院党委书记何志通在一起。】

 

何志通是广东省中医院原党委书记兼副院长。1925年出生于河北，12岁即加入少年先锋队宣传队， 13岁加入八路军，1942年加入中国共产党。解放后，先后在暨南大学、广州中医学院附属医院工作，1979年至1983年间担任广东省中医院党委书记兼副院长。

随着年龄的增长和革命工作的磨练，何志通同志对党的认识与了解逐渐加深，对共产主义思想和革命的信念也日益坚定。1942年，何志通光荣地加入中国共产党。1943年后到抗战结束以及在解放战争过程中，何志通同志一直在部队中从事宣传和文艺工作。多年的革命工作和战争炮火的洗礼，练就了何志通同志踏实的工作作风、坚韧不拔的精神，对他在社会主义建设事业中的工作产生了重要的影响。

铮铮铁骨 信仰不坠

**肖玉英教授身上充满了传奇色彩，她不仅是一名为人民健康服务的好医生，还是保家卫国的战士，曾获得了一枚沉甸甸的抗日勋章。**

早在高中时期，萧玉英受老师的影响开始接触共产主义思想，出于对共产主义的坚定信念和对日本帝国主义的愤恨，她瞒着父亲开始从事党的地下组织工作，17岁时即被吸收成为了一名共产党员。

1940年，高中毕业后的萧玉英进入到福建协和大学生物系读书，但她并没有停止革命工作。当年夏天，她参加了福建省地下省委在崇安武夷山的培训班，后被派回建瓯做地下党革命工作。在建瓯的这段时间，萧玉英同志主要从事学生运动、妇女解放运动，传播共产主义思想，破除封建迷信、旧风俗、旧思想，揭穿国民党反动派的虚假面貌。也因此多次遭受国民党反动派的迫害，敌人多次将她逮捕入狱。但这并没有削弱萧玉英同志的革命信念与热情，即便在监狱里，她依然与同志们一起思虑着革命事业。正是这段革命经历练就了萧玉英同志坚定执着的革命信念、艰苦奋斗的精神。

抗日战争胜利后，萧玉英同志又历经了人民解放战争、社会主义建设、文化大革命等起起伏伏的岁月。1972年，萧玉英同志到广东省中医院从事内科工作后，继续以革命般的热情与精神投身到医疗卫生事业中。她严谨认真的工作作风，无私奉献的精神是同事们的楷模。她以自己的智慧为人民解除疾病痛楚，为医院并培养了众多的人才，为广东省中医院中西医结合的医教研工作作出了杰出的贡献。

肖玉英教授虽然现在已经不能流畅的讲话，但依然值得晚辈们尊敬！医护人员深情地表示，**“肖玉英教授是我们医院的宝贵财富，广东省中医院的每一分成就都承载着老前辈的辛劳和汗水。我们将永远不忘你们的好传统、好风范。”**
